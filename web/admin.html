Point Aperture at Aegis

Aegis is a synchronous pre_request hook. In Aperture, add a hook named aegis whose URL is this instance’s /v1/pre-request, and a grant with send_hooks that sends user_message and request_body. Use fail-open so chat keeps working if Aegis is down. Full operator notes live in docs/configuring-aperture.md.
