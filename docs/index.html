Aegis

A Go service that sits between Tailscale Aperture and music APIs. When an agent mentions Spotify, YouTube Music, or Amazon Music — or asks about playlists/liked songs without naming a service — Aegis intercepts the LLM request, injects instructions to call its proxy, then mediates real API calls with OAuth, caching, permissions, and a neutral multi-source library model.

01Why Aegis exists

Aperture is Tailscale’s LLM gateway. Its guardrails can rewrite or block provider-bound chat requests, but they do not intercept MCP tool calls. You cannot “guard” an agent’s Spotify API call by sitting in front of the model alone.

Aegis uses a two-component architecture instead:

1. Pre-request hook

Aperture calls POST /v1/pre-request before the LLM sees the user message. Aegis scans the text for service names and library keywords (“what playlists do I have?”). If found, it returns {"action":"modify"} with a system message telling the agent to call Aegis’s proxy/library endpoints instead of external APIs.

2. Service proxy + unified library

Agents call /v1/services/{id}/… or /v1/library/{kind}. Aegis attaches the user’s OAuth token, maps verbose upstream JSON into a compact neutral shape, merges same-named items across services, enforces per-data-type permissions, caches GETs, and never exposes tokens to the agent.

Design rule: agents authenticate to Aegis (Tailscale identity or API key). They never hold Spotify/YouTube/Amazon OAuth credentials.

02Architecture at a glance

Control plane (orange): Aperture asks Aegis what to do with the chat. Data plane (green/blue): the agent later calls Aegis’s library or proxy endpoints.

03Startup: wiring the Server

Everything hangs off one struct. main() parses flags, loads config, builds the token store and identity resolver, registers three connectors, then serves HTTP.

# FastAPI / Starlette style

    app.get(path)(auth(handler))
app.api_route("/v1/services/{path:path}")(auth(srv.handle_service_proxy))

Why one Server struct? Go has no dependency-injection container. Methods on *Server are ordinary functions that close over shared state. The same pattern as a Python class holding self.config, self.cache, and so on — except handlers are bound via method values (srv.HandlePreRequest) rather than being free functions.

04Two-legged auth

Aegis has two callers, and they authenticate differently:

LegWho calls AegisHow they authenticate
Hook Aperture (POST /v1/pre-request) Usually the shared API key. In tailnet mode Aperture must also present tailnet identity.
Agent data The LLM agent (/v1/library/…, /v1/services/…) Preferred: Tailscale identity (Serve headers or WhoIs). Fallback: API key in auto/api-key modes.
Go — AuthMiddleware
func (s *Server) AuthMiddleware(next http.HandlerFunc) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        id, idErr := s.resolveIdentity(r)
        switch s.authMode {
        case AuthModeAPIKey:
            if !s.checkAPIKey(r) { s.deny(…); return }
            next(w, r); return
        case AuthModeTailnet:
            if id == nil || !loginAllowed(id, s.allowedLogins) {
                s.deny(…); return
            }
            next(w, withPeerIdentity(r, id)); return
        default: // auto
            if id != nil && loginAllowed(id, s.allowedLogins) {
                next(w, withPeerIdentity(r, id)); return
            }
            if s.apiKey != "" && s.checkAPIKey(r) {
                next(w, r); return
            }
            s.deny(…); return
        }
    }
}
Python
def auth_middleware(s, next_handler):
    def wrapper(w, r):
        peer, err = s.resolve_identity(r)
        if s.auth_mode == "api-key":
            if not s.check_api_key(r):
                return s.deny(w, r, "missing or invalid API key")
            return next_handler(w, r)
        if s.auth_mode == "tailnet":
            if peer is None or not login_allowed(peer, s.allowed_logins):
                return s.deny(w, r, "tailnet identity required")
            r.peer = peer
            return next_handler(w, r)
        # auto: identity first, then API key
        if peer is not None and login_allowed(peer, s.allowed_logins):
            r.peer = peer
            return next_handler(w, r)
        if s.api_key and s.check_api_key(r):
            return next_handler(w, r)
        return s.deny(w, r, "unauthorized")
    return wrapper

Identity is two resolvers, not one. ServeHeaderResolver trusts Tailscale Serve headers (Tailscale-User-Login, tags). WhoIsResolver queries tailscaled over a Unix socket. MultiResolver tries them in order. Successful identity is stuffed into the request context via withPeerIdentity — the Go equivalent of request-local state.

05Pre-request hook flow

Pre-request decision tree. Service match injects connector instructions; service-less library questions inject unified endpoints; otherwise allow.

Go — handler.go
matched := s.config.FindMatchingServices(payload.UserMessage)

var libraryInstructions []string
if len(matched) == 0 {
    libraryInstructions = s.libraryHintsForMessage(payload.UserMessage)
}
if len(matched) == 0 && len(libraryInstructions) == 0 {
    writeGuardrailResponse(w, GuardrailResponse{Action: ActionAllow})
    return
}

// any blocked service rejects the whole chat request
for _, svc := range matched {
    if svc.Action == "block" {
        writeGuardrailResponse(w, GuardrailResponse{
            Action: ActionBlock, Message: …})
        return
    }
}

for _, svc := range matched {
    if allDataDenied(svc.Permissions) { continue }
    if connector, ok := s.connectors[svc.ID]; ok {
        instructions = append(instructions,
            connector.SystemInstructions(s.baseURL))
    }
}
instructions = append(instructions, libraryInstructions...)
Python
matched = s.config.find_matching_services(payload.user_message)

library_instructions = []
if not matched:
    library_instructions = s.library_hints_for_message(payload.user_message)
if not matched and not library_instructions:
    return GuardrailResponse(action="allow")

for svc in matched:
    if svc.action == "block":
        return GuardrailResponse(
            action="block",
            message=f"blocked: access to {svc.name} not allowed")

instructions = []
for svc in matched:
    if all_data_denied(svc.permissions):
        continue
    connector = s.connectors.get(svc.id)
    if connector:
        instructions.append(connector.system_instructions(s.base_url))

instructions.extend(library_instructions)

Fail-open. If the payload cannot be parsed, Aegis allows the request rather than breaking every LLM call. The hook is advisory for inject services and hard-blocking only for action: "block".

06ServiceConnector interface

Each music service is a connector that can describe itself, inject agent instructions, and handle proxied paths. Optional provider interfaces let a connector opt into unified library datasets without the core knowing Spotify vs YouTube.

Go — interfaces

    SystemInstructions(baseURL string) string
    HandleProxy(w http.ResponseWriter, r *http.Request, remainingPath string)
}

    def capabilities(self) -> ServiceCapabilities: ...

# Runtime check in Go:
#   provider, ok := any(connector).(PlaylistProvider)
# Python: isinstance(connector, PlaylistProvider)

Go insight: any(connector).(P) is a type assertion. The library pipeline walks s.connectors, asserts each connector to PlaylistProvider / LikedTrackProvider / etc., and only fans out to services that implement the interface. Adding a new connector is registering it in main.go — no switch on service ID in the core.

07Service proxy

HandleServiceProxy is the data-plane entry point. It classifies the path, checks permissions, then either delegates to a connector or does a generic cache + OAuth + forward.

Parse service ID and remaining path
/v1/services/spotify/me/tracks → id=spotify, path=/me/tracks
Lookup service; special-case /capabilities
Connector metadata filtered by that service’s permissions map.
Enforce action: block and data-type permissions
AllowDataPermission classifies the path via DataTypeForPath (tracks, playlists, player, …).
Delegate to connector, or generic forward
Connectors transform and paginate; generic path injects OAuth and caches GETs.

08Unified library pipeline

The library is the heart of the “unified taste” design. Six datasets (playlists, liked tracks, albums, artists, contacts, photos) share one generic pipeline. Adding a kind is a registry entry plus a thin typed handler — not another copy-paste fan-out.

Generic library pipeline. Connectors that implement the provider interface are fanned out in parallel; failures degrade to per-service status, not a 500.

Go — librarykind.go (generics)
type LibraryKind struct {
    ID, Path, PermType, Label, Usage string
    Keywords []string
    HasProviders func(*Server) bool
    Readable     func(*Server) bool
}

func handleLibraryAggregate[T any](
    s *Server, w http.ResponseWriter, r *http.Request,
    spec libraryKindSpec[T],
) {
    // cache → collectProviders → fan-out goroutines → merge → encode
    for _, t := range targets {
        wg.Add(1)
        go func(t namedLister[T]) {
            defer wg.Done()
            defer func() {
                if rec := recover(); rec != nil {
                    err = fmt.Errorf("provider panic: %v", rec)
                }
            }()
            items, truncated, err = t.list(ctx)
            // map err → bySvc[id] = ok | unauthorized | error
        }(t)
    }
    wg.Wait()
    merged := spec.merge(all)
    s.cache.Set(kind.CacheKey(), result, 60*time.Second)
}
Python — same shape without generics
def handle_library_aggregate(s, w, r, spec):
    cached = s.cache.get(spec.kind.cache_key())
    if cached:
        return cached

    targets, denied = spec.collect(s)
    if not targets:
        return 403 if denied else 404

    async def one(t):
        try:
            return await t.list(ctx), "ok"
        except Unauthorized:
            return [], "unauthorized"
        except Exception as e:
            return [], "error"

    results = await asyncio.gather(*[one(t) for t in targets])
    all_items = [i for items, _ in results for i in items]
    merged = spec.merge(sorted(all_items, key=spec.sort_key))
    s.cache.set(spec.kind.cache_key(), encode(merged), ttl=60)

Why Go generics here? handleLibraryAggregate[T] keeps the pipeline type-safe ([]Track, []Playlist, []Contact) while sharing one implementation. Python would use duck typing or TypeVar; Go needs the type parameter so namedLister[T].list returns the right slice type without interface{} casts everywhere.

09Neutral models & cross-service sync

Service identity never lives on the user-facing object. A playlist is a Playlist with a list of sources[] — one per service copy. Same-named playlists on Spotify and YouTube become one entity.

Go — models.go + match.go
type Playlist struct {
    Name        string            `json:"name"`
    Description string            `json:"description,omitempty"`
    Owner       string            `json:"owner,omitempty"`

func NormalizeIdentityKey(name string) string {
    s := strings.ToLower(strings.TrimSpace(name))
    s = strings.ReplaceAll(s, " - topic", "")
    s = strings.Join(strings.Fields(s), " ")
    return s
}

10Data permissions

Beyond action: inject|block, each service can restrict what kind of access agents have to specific data types:

aegis.json
"permissions": {
  "default": "read",
  "playlists": "read",
  "tracks": "read",
  "player": "none",
  "recommendations": "none"
}
Go — permissions.go
func (p Permissions) For(dataType string) string {
    if p == nil {
        return DefaultAccessType // read-write
    }
    if level, ok := p[dataType]; ok {
        return normalizeAccess(level)
    }
    if level, ok := p[PermissionDefaultKey]; ok {
        return normalizeAccess(level)
    }
    return DefaultAccessType
}

// DataTypeForPath: /me/tracks → "tracks"
//                  /me/player → "player"
//                  /playlists → "playlists"
LevelAllowed methods
nonenone — 403 for that data type
readGET, HEAD
writePOST, PUT, PATCH, DELETE
read-writeboth (also accepts full / rw)

Enforcement happens in three places: the service proxy, the unified library endpoints, and the /capabilities response (denied types/operations are hidden from agents). Pre-request injection also lists denied types so agents do not try them.

11OAuth & token storage

Login
GET /v1/auth/{id}/login generates CSRF state (TTL 10m), redirects to the provider with scopes.
Callback
GET /v1/auth/{id}/callback validates state (one-shot delete), exchanges the code for tokens, saves encrypted.
Refresh on use
getValidToken refreshes if expired (30s skew). Refresh failure falls back to the expired access token as last resort.
Go — tokens.go (AES-256-GCM)
// PBKDF2-SHA256, 100k iterations → AES-256 key
func deriveKey(pass string, salt []byte) []byte {
    return pbkdf2.Key(
        []byte(pass), salt, pbkdf2Iter, pbkdf2KeyLen, sha256.New)
}

// On disk: {"version":1,"salt":"…","tokens":{"spotify":"b64…"}}
// Each token value is base64(AES-GCM(json(OAuthToken)))

func (tok *OAuthToken) IsExpired(skew time.Duration) bool {
    return tok.Expiry.Add(-skew).Before(time.Now())
}

type Cache struct {
    mu    sync.RWMutex
    items map[string]cacheEntry
}

func (c *Cache) Get(key string) (string, bool) {
    c.mu.RLock()
    defer c.mu.RUnlock()
}

func (c *Cache) Set(key, value string, ttl time.Duration) {
    c.mu.Lock()          // exclusive
    defer c.mu.Unlock()
}
Python
from threading import RLock

class Cache:
    def __init__(self):
        self._lock = RLock()
        self.items = {}

    def get(self, key):
        with self._lock:
            return self.items.get(key)

# asyncio: use asyncio.Lock() — no reader/writer split.
