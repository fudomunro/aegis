A Go service that sits between Tailscale Aperture and music APIs. When an agent mentions Spotify, YouTube Music, or Amazon Music, Guardian intercepts the LLM request, injects instructions to call its proxy, then mediates real API calls with OAuth, caching, and a neutral playlist model.

01Why Guardian exists

Aperture is Tailscale’s LLM gateway. Its guardrails can rewrite or block provider-bound chat requests, but they do not intercept MCP tool calls. So you cannot “guard” an agent’s Spotify API call by sitting in front of the model alone.

Guardian uses a two-component architecture instead:

1. Pre-request hook

Aperture calls POST /v1/pre-request before the LLM sees the user message. Guardian scans the text for service names. If found, it returns {"action":"modify"} with a system message telling the agent “call Guardian’s proxy, not Spotify directly.”

2. Service proxy + library

Agents then call /v1/services/{id}/… or /v1/library/playlists. Guardian attaches the user’s OAuth token, transforms verbose upstream JSON into a compact neutral shape, caches GETs, and never exposes tokens to the agent.

Design rule: agents authenticate to Guardian (Tailscale identity or API key). They never hold Spotify/YouTube/Amazon OAuth credentials.

Control plane (orange): Aperture asks Guardian what to do with the chat. Data plane (green/blue): the agent later calls Guardian’s proxy endpoints.

04Two-legged auth

Guardian has two kinds of callers, and they authenticate differently. A single middleware decides, based on authMode.

LegWhoEndpointPreferred credential
Hook Aperture POST /v1/pre-request API key in hook config; in tailnet mode also Serve identity / WhoIs
Agent data LLM agent / MCP host /v1/library/…, /v1/services/… Tailscale identity (Serve headers or WhoIs). API key is fallback in auto/api-key
Go — AuthMiddleware (handler.go)
func (s *Server) AuthMiddleware(
    next http.HandlerFunc,
) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        id, idErr := s.resolveIdentity(r)

        switch s.authMode {
        case AuthModeAPIKey:
            if !s.checkAPIKey(r) { s.deny(...); return }
            next(w, r)

        case AuthModeTailnet:
            if id == nil || !loginAllowed(id, s.allowedLogins) {
                s.deny(...); return
            }
            next(w, withPeerIdentity(r, id))

        default: // auto: identity first, then API key
            if id != nil && loginAllowed(id, s.allowedLogins) {
                next(w, withPeerIdentity(r, id)); return
            }
            if s.apiKey != "" && s.checkAPIKey(r) {
                next(w, r); return
            }
            s.deny(...)
        }
    }
}
Python — equivalent middleware
def auth_middleware(srv: Server):
    def decorator(handler):
        async def wrapper(request: Request):
            identity = await srv.resolve_identity(request)
            mode = srv.auth_mode

            if mode == "api-key":
                if not srv.check_api_key(request):
                    return JSONResponse(
                        {"error": "unauthorized"}, status_code=401)
            elif mode == "tailnet":
                if identity is None or not login_allowed(identity, srv.allowed_logins):
                    return deny(request)
                request.state.identity = identity
            else:  # auto
                if identity and login_allowed(identity, srv.allowed_logins):
                    request.state.identity = identity
                elif srv.api_key and srv.check_api_key(request):
                    pass
                else:
                    return deny(request)
            return await handler(request)
        return wrapper
    return decorator

How identity is resolved

ServeHeaderResolver
Reads Tailscale-User-Login / Tailscale-Node-Tags headers. Only trustworthy when the request arrived through tailscale serve.
WhoIsResolver
Asks local tailscaled over a Unix socket (/var/run/tailscale/tailscaled.sock) who the peer is. Trustworthy for on-tailnet connections.
MultiResolver
Tries them in order. identity.go also warns when Aperture’s claimed login differs from the actual tailnet peer.

05Pre-request hook flow

This is the control plane. Aperture POSTs a payload with user_message and the original request_body. Guardian decides allow / block / modify.

Decision tree in HandlePreRequest (handler.go). Fail-open: unreadable body or parse errors return allow.

Go — matching + injection
// config.go — substring match on name/aliases
func (c *Config) FindMatchingServices(
    userMessage string,
) []Service {
    lower := strings.ToLower(userMessage)
    var matched []Service
    for _, svc := range c.Services {
        if matchesService(svc, lower) {
            matched = append(matched, svc)
        }
    }
    return matched
}

// handler.go — prepend a system message
sysMsg, _ := json.Marshal(map[string]string{
    "role": "system", "content": content,
})
req.Messages = append(
    []json.RawMessage{sysMsg}, req.Messages...)
Python — equivalent
def find_matching_services(
    services: list[Service], message: str
) -> list[Service]:
    lower = message.lower()
    return [
        s for s in services
        if s.name.lower() in lower
        or any(a.lower() in lower for a in s.aliases)
    ]

def inject_system_message(body: dict, content: str) -> dict:
    messages = body.get("messages", [])
    body["messages"] = [
        {"role": "system", "content": content},
        *messages,
    ]
    return body

Connector-backed services inject connector.SystemInstructions(baseURL) (a rich endpoint catalog). Services without a connector get a short generic “use the proxy at …” string. Unnamed playlist questions get librarySystemInstructions() pointing at the unified library.

06ServiceConnector interface

The central abstraction. Any service that wants intelligent proxying implements three methods. Registration is by service ID in Server.connectors.

Go — handler.go
type ServiceConnector interface {
    // Metadata for GET /v1/services/{id}/capabilities
    Capabilities() ServiceCapabilities

    // System message injected into LLM requests
    SystemInstructions(baseURL string) string

    // Handle a proxied request for this service
    HandleProxy(
        w http.ResponseWriter,
        r *http.Request,
        remainingPath string,
    )
}

type ServiceCapabilities struct {
    DataTypes []DataTypeCapability `json:"data_types"`
}
type DataTypeCapability struct {
    Name        string      `json:"name"`
    Description string      `json:"description"`
    Operations  []Operation `json:"operations"`
}

    Name        string       `json:"name"`
    Description string       `json:"description"`
    Method      string       `json:"method"`
    Path        string       `json:"path"`
    Parameters  []Parameter  `json:"parameters,omitempty"`
    Response    ResponseSpec `json:"response"`
}

Why sources[]? One logical playlist (“Road Trip”) may exist on Spotify and YouTube Music. Top-level fields describe the user-facing thing; service-local IDs and deep links live only in sources. Matching across services is currently text-based (NormalizeIdentityKey); better entity resolution is deferred (issue #4).

08Proxy delegation

HandleServiceProxy is the data-plane entry. It parses /v1/services/{id}/{path…}, then either answers capabilities, delegates to a connector, or falls back to generic OAuth-forwarding.

Proxy decision flow in proxy.go. Connectors win; generic forwarding is the fallback for configured-but-uncustomized services.

proxy.go — the delegation fork
// If a connector is registered for this service, delegate to it.
if connector, ok := s.connectors[serviceID]; ok {
    connector.HandleProxy(w, r, remainingPath)
    return
}

// Generic path: build upstream URL, check cache, inject OAuth, forward.
upstreamURL := strings.TrimRight(svc.Endpoint, "/") + remainingPath
if r.Method == http.MethodGet {
    if cached, ok := s.cache.Get(cacheKey); ok {
        w.Header().Set("X-Guardian-Cache", "hit")
        io.WriteString(w, cached)
        return
    }
}
if tok := s.getValidToken(serviceID, logger); tok != "" {
    upstreamReq.Header.Set("Authorization", "Bearer "+tok)
}

09Neutral library & playlist sync

When an agent asks “what playlists do I have?” without naming a service, Guardian points it at GET /v1/library/playlists. That endpoint fans out to every connector that implements PlaylistProvider, then merges same-named playlists.

Fan-out → merge. Parallel fetch with sync.WaitGroup; per-service failures become by_service status, not a hard fail.

func NormalizeIdentityKey(name string) string {
    s := strings.ToLower(strings.TrimSpace(name))
    s = strings.ReplaceAll(s, " - topic", "")
    s = strings.Join(strings.Fields(s), " ")

10OAuth & token storage

Users authorize once via browser. Guardian stores tokens encrypted at rest and auto-refreshes them when the proxy needs a valid access token.

Login/callback stay public (no auth middleware) so the provider can redirect the user’s browser. Status/revoke require auth.

Go — tokens.go
const (
    pbkdf2Iter = 100_000
    pbkdf2KeyLen = 32 // AES-256
)

func deriveKey(pass string, salt []byte) []byte {
    return pbkdf2.Key(
        []byte(pass), salt,
        pbkdf2Iter, pbkdf2KeyLen, sha256.New,
    )
}

// On-disk: {version, salt, tokens:{service → base64(nonce‖ciphertext)}}
func (ts *TokenStore) encrypt(plain []byte) (string, error) {
    block, _ := aes.NewCipher(ts.key)
    gcm, _ := cipher.NewGCM(block)
    nonce := make([]byte, gcm.NonceSize())
    io.ReadFull(rand.Reader, nonce)
    return base64.EncodeToString(
        gcm.Seal(nonce, nonce, plain, nil)), nil
}
Python — cryptography
from hashlib import pbkdf2_hmac
from cryptography.hazmat.primitives.ciphers.aead import AESGCM
import os, base64

def derive_key(passphrase: str, salt: bytes) -> bytes:
    return pbkdf2_hmac(
        "sha256", passphrase.encode(), salt,
        100_000, dklen=32,
    )

def encrypt(key: bytes, plain: bytes) -> str:
    nonce = os.urandom(12)
    ct = AESGCM(key).encrypt(nonce, plain, None)
    return base64.b64encode(nonce + ct).decode()

# and rewrites tokens.json on every Save/Delete.

spotify.go — transformSavedTracks
func (c *SpotifyConnector) transformSavedTracks(
    raw map[string]any,
) map[string]any {
    items, _ := raw["items"].([]any)
    tracks := make([]map[string]any, 0, len(items))
    for _, item := range items {
        saved, ok := item.(map[string]any)
        if !ok { continue }
        track, _ := saved["track"].(map[string]any)
        if track == nil { continue }
        tracks = append(tracks, map[string]any{
            "name":    track["name"],
            "artists": extractNames(track, "artists"),
            "album":   extractNested(track, "album", "name"),
            "id":      track["id"],
            "uri":     track["uri"],
        })
    }
    return map[string]any{"tracks": tracks, "total": raw["total"]}
}

Stripped: images, external_urls, followers, release_date, popularity, pagination chrome. Pagination is auto-fetched (fetchAllPagesRaw / fetchAllPages) so agents see a complete list.

type Cache struct {
    mu    sync.RWMutex
    items map[string]cacheEntry
}

func (c *Cache) Get(key string) (string, bool) {
    c.mu.RLock()
    defer c.mu.RUnlock()
    // concurrent Get()s share the lock
}

func (c *Cache) Set(key, value string, ttl time.Duration) {
    c.mu.Lock()          // exclusive
    defer c.mu.Unlock()

from threading import RLock

class Cache:
    def __init__(self):
        self._lock = RLock()
        self.items = {}

    def get(self, key):
        with self._lock:
            return self.items.get(key)
