01Why Aegis exists

Aperture is Tailscale’s LLM gateway. Guardrails can rewrite or block provider-bound chat requests, but they do not intercept the agent’s later tool/API calls. You cannot “guard” a Spotify request by sitting only in front of the model.

Aegis therefore has two cooperating jobs:

1. Pre-request hook

Aperture calls POST /v1/pre-request before the LLM sees the message. Aegis scans for service names and library keywords (“what playlists do I have?”). Matches produce {"action":"modify"} plus a system message that points the agent at Aegis endpoints instead of raw provider APIs. Failures fail-open (allow).

2. Proxy + unified library

Agents call /v1/services/{id}/… or /v1/library/{kind}. Aegis resolves OAuth connections, enforces permissions, caches successful GETs, maps provider JSON into neutral models, merges cross-service items, and keeps tokens off the agent.

Product rules that shape the code: named services first · fail-open on fetch/parse errors · Aegis owns OAuth · connections (not per-surface OAuth) · Aegis does not store media · coverage floor 80% · no Tailscale Funnel.

02Architecture at a glance

Control plane: Aperture asks Aegis what to do with the chat. Data plane: the agent later calls Aegis library/proxy endpoints; connectors talk to providers with stored tokens.

04Auth model

Aegis authenticates callers of Aegis, not provider APIs:

LegWhoHow
Hook Aperture → POST /v1/pre-request API key and/or tailnet identity, depending on mode.
Agent data Agent → library / proxy / auth status Preferred: Tailscale identity (Serve headers or WhoIs). Fallback: API key in auto/api-key.
OAuth browser User → /v1/auth/{id}/login|callback Public by design (redirect flow). Tokens never returned to agents.
Go — AuthMiddleware
func (s *Server) AuthMiddleware(next http.HandlerFunc) http.HandlerFunc {
    return func(w http.ResponseWriter, r *http.Request) {
        id, idErr := s.resolveIdentity(r)
        switch s.authMode {
        case AuthModeAPIKey:
            if !s.checkAPIKey(r) { s.deny(…); return }
            next(w, r); return
        case AuthModeTailnet:
            if id == nil || !loginAllowed(id, s.allowedLogins) {
                s.deny(…); return
            }
            next(w, withPeerIdentity(r, id)); return
        default: // auto — identity first, then API key
            if id != nil && loginAllowed(id, s.allowedLogins) {
                next(w, withPeerIdentity(r, id)); return
            }
            if s.apiKey != "" && s.checkAPIKey(r) {
                next(w, r); return
            }
            s.deny(…); return
        }
    }
}
Python
def auth_middleware(s, next_handler):
    def wrapper(w, r):
        peer, _err = s.resolve_identity(r)
        if s.auth_mode == "api-key":
            if not s.check_api_key(r):
                return s.deny(w, r)
            return next_handler(w, r)
        if s.auth_mode == "tailnet":
            if peer is None or not login_allowed(peer, s.allowed_logins):
                return s.deny(w, r)
            r.peer = peer
            return next_handler(w, r)
        # auto
        if peer is not None and login_allowed(peer, s.allowed_logins):
            r.peer = peer
            return next_handler(w, r)
        if s.api_key and s.check_api_key(r):
            return next_handler(w, r)
        return s.deny(w, r)
    return wrapper

Identity is assembled from resolvers, not one global: ServeHeaderResolver trusts Tailscale Serve headers; WhoIsResolver queries tailscaled over a Unix socket; MultiResolver tries them in order. Successful identity goes into request context via withPeerIdentity — Go’s request-local state, analogous to Flask g / middleware-stored attributes.

def handle_pre_request(self, w, r):
    payload = parse(r.body)  # fail-open → allow
    matched = self.config.find_matching_services(payload.user_message)
    lib = []
    if not matched:
        lib = self.library_hints_for_message(payload.user_message)
    if not matched and not lib:
        return guardrail(w, action="allow")
    if any(svc.action == "block" for svc in matched):
        return guardrail(w, action="block", message=…)
    instructions = []
    for svc in matched:
        if svc.action != "inject":
            continue
        conn = self.connectors.get(svc.id)
        instructions.append(
            conn.system_instructions(self.base_url) if conn
            else generic_proxy_instruction(svc, self.base_url)
        )
        instructions.extend(permission_notices(svc.permissions))
    instructions.extend(write_policy_notices(matched))
    instructions.extend(lib)
    modified = inject_system_message(payload.request_body, "\n\n".join(instructions))
    if modified is None:
        return guardrail(w, action="allow")
    return guardrail(w, action="modify", request_body=modified)

Fail-open is intentional. Parse errors, missing injectable services, and injection failures return allow. The hook must not break chat when Aegis is unhealthy. Blocks are reserved for explicit action: "block" service policy.

Empty operations still matter. DataTypeCapability.Operations is a list of structured Operation values (method, path, parameters, response spec) — not bare strings. An empty list means “type recognized, not implemented”.

Never hardcode upstream bases. Connectors must read config.GetService(id).Endpoint so mock tests and custom endpoints work.

func runConnectorProxy(s *Server, w http.ResponseWriter, r *http.Request, remainingPath string, opts connectorProxyOpts) {
    token := s.getValidToken(opts.serviceID, logger)
    if token == "" {
        writeJSONError(w, http.StatusUnauthorized, "… authorize at /v1/auth/"+opts.serviceID+"/login")
        return
    }
    // optional mapUpstream(path, query) — provider path quirks stay in the connector
    cacheKey := opts.serviceID + ":" + r.URL.RequestURI()
    if r.Method == http.MethodGet {
        if cached, ok := s.cache.Get(cacheKey); ok {
            w.Header().Set("X-Aegis-Cache", "hit")
            io.WriteString(w, cached); return
        }
    }
    data, status, err := doUpstreamRequest(r.Context(), r.Method, upstreamURL, r.Body, token)
    if status == http.StatusUnauthorized { /* re-auth hint */ }
    if status == http.StatusTooManyRequests { /* Retry-After + 429 */ }
    if opts.expandPages != nil && r.Method == http.MethodGet { data = mergePages(…) }
    transformed := opts.transform(remainingPath, data, logger)
    if r.Method == http.MethodGet && status == http.StatusOK {
        s.cache.Set(cacheKey, string(result), ttl)  // cache 200 GET only
    }
}

Prefer shared helpers. New connector work should call runConnectorProxy / doUpstreamRequest / aegisHTTPClient instead of inventing another http.DefaultClient call site.

08Unified library pipeline

The library answers questions like “what playlists do I have?” without forcing the agent to know which provider holds which copy. A LibraryKind registry plus one generic aggregate pipeline avoids cloning the same fan-out logic for every dataset.

Registered kinds at this version: playlists, tracks, albums, artists, contacts, photos, events, messages, transactions, places. Extra library routes: /v1/library/review, /v1/library/links, POST /v1/library/mirror.

def collect_providers(s, protocol, list_method, perm_type):
    targets, denied = [], []
    for cid, connector in s.connectors.items():
        svc = s.config.get_service(cid)
        if svc is None or svc.action == "block":
            continue
        if not isinstance(connector, protocol):
            continue
        if not svc.permissions.allows_read(perm_type):
            denied.append(cid); continue
        targets.append((cid, getattr(connector, list_method)))
    return targets, denied

09Neutral models, match, canonical

Neutral models live at the library boundary (models.go). Provider quirks stay inside connectors. Service-local identity is never top-level: it lives in sources[] so one logical item can point at copies on several services.

Cross-service match priority

Tracks: ISRC / MusicBrainz recording MBID → title+artist (+duration guard). Albums: UPC / release-group MBID → title+artist. Artists: MBID → normalized name (strip YouTube “ - Topic”). Playlists: explicit entity link → same title. Preferred durable IDs beat name-only merges.

Canonical + write policy

Aegis does not store media. Config canonical_for marks the non-Aegis home per kind (at most one non-blocked service per kind). Connectors may also mark inherent ownership (e.g. Google Photos bytes). Pre-request injection tells agents to prefer the home for writes/mirrors.

Go — match.go identity key
func NormalizeIdentityKey(name string) string {
    s := strings.ToLower(strings.TrimSpace(name))
    s = strings.ReplaceAll(s, " - topic", "")
    s = strings.Join(strings.Fields(s), " ")
    return s
}

10Data permissions

Beyond action: inject|block, each service can restrict which data types agents may touch. Permissions are data on the service config, enforced on proxy, library, capabilities, and injection.

Go — permissions.go
func (p Permissions) For(dataType string) string {
    if p == nil { return DefaultAccessType } // unrestricted
    if level, ok := p[dataType]; ok { return normalizeAccess(level) }
    if level, ok := p[PermissionDefaultKey]; ok { return normalizeAccess(level) }
    return DefaultAccessType
}

Known types include user, tracks, albums, artists, playlists, search, player, channels, library, recommendations, contacts, photos. Unknown paths fall through to default. Denied types are hidden from agent capabilities and omitted from injection.

11OAuth connections & tokens

Go — proxy.go token path
func (s *Server) getValidToken(serviceID string, logger *slog.Logger) string {
    connectionID := s.config.connectionIDForService(serviceID)
    tok := s.tokens.Get(connectionID)   // keyed by connection, not surface
    if tok == nil { return "" }
    if !scopesSatisfy(tok.Scopes, s.config.requiredScopes(serviceID)) {
        return ""  // surface unauthorized; connection may still be fine
    }
    if !tok.IsExpired(30 * time.Second) { return tok.AccessToken }
    refreshed, err := s.RefreshToken(connectionID) // singleflight
    if err != nil { return tok.AccessToken } // try stale as fallback
    return refreshed.AccessToken
}
Python
def get_valid_token(self, service_id, logger):
    connection_id = self.config.connection_id_for_service(service_id)
    tok = self.tokens.get(connection_id)
    if tok is None:
        return ""
    if not scopes_satisfy(tok.scopes, self.config.required_scopes(service_id)):
        return ""
    if not tok.is_expired(30):
        return tok.access_token
    refreshed = self.refresh_token(connection_id)  # coalesced
    if refreshed is None:
        return tok.access_token
    return refreshed.access_token

Admin/API responses expose token presence, scopes, and expiry only — never client secrets, access tokens, or refresh tokens. Secrets stay out of git (aegis.json, tokens.json are local).
