Agent kit

Talk to the demo
with a real agent.

A read-only Aegis filled with synthetic personal data. Paste the brief below into an agent that can run curl, then ask about the journey, the war, or the mail archive.

Synthetic demo — not your data. The public Aegis product is a private tailnet service. This kit is for a separate, read-only demo instance. You need an agent with Bash / HTTP (Claude Code, Cursor, Codex, or similar). Chat-only agents cannot call the API.

If the agent refuses

    
    
      
  • “I don’t have an API key” — the key never reached the tool. Re-paste the brief; keep BASE_URL and API_KEY in the same message as the curl.
    • 
      
  • “I can’t query localhost” — chat-only browser agents cannot reach your machine. Use Claude Code / Cursor / Codex, or run curl yourself.
    • 
      
  • Empty answers — try the smoke test. If that works, ask more specifically (dates, subjects).
